# fotolapissable · Riposto

App turistica interattiva per Riposto (CT) — realizzata da [Michele Cipriano](https://fotolapissable.it).

## Funzionalità
- 🗺 Mappa interattiva con 12 luoghi da visitare (coordinate GPS verificate sul campo)
- 🌤 Meteo in tempo reale (Open-Meteo)
- 🚌 Orari trasporti: Trenitalia, Circumetnea FCE, Zappalà e Torrisi, Interbus, AST
- 🍋 Sapori tipici di Riposto
- 📷 Portfolio fotografico: [fotolapissable.it](https://fotolapissable.it)
- 📍 Geolocalizzazione turista
- 🗺/🛰/🌿/🌙 Cambio tipo mappa (Voyager, Satellite, Terreno, Scuro)
- 🇮🇹/🇬🇧 Toggle lingua IT / EN

## Come pubblicare su GitHub Pages

1. Crea un nuovo repository su GitHub (es. `riposto` o `fotolapissable-riposto`)
2. Carica questo file `index.html` e il file `.nojekyll` nella root del repository
3. Vai in **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. L'app sarà disponibile su `https://[tuo-username].github.io/riposto`

## Dominio personalizzato (facoltativo)

Per usare `riposto.fotolapissable.it`:
1. In Settings → Pages → Custom domain → inserisci `riposto.fotolapissable.it`
2. Nel pannello DNS di Aruba, aggiungi un record CNAME:
   - Nome: `riposto`
   - Valore: `[tuo-username].github.io`

## Aggiornare i contenuti

Usa il file `fotolapissable_contenuti_app.xlsx` per modificare i dati e poi inviarlo a Claude per rigenerare l'`index.html`.
